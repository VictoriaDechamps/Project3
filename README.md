# Project3
SSCI 591 Project 3

### What this map shows
This map shows parks and open spaces in LA County.

### Starting sample (name and link)
The starting sample is the Intro to Feature Layer example provided in the assignment instrucitons: https://developers.arcgis.com/javascript/latest/sample-code/intro-featurelayer/

### What I changed
I changed the layer being shown, the title, basemap, symbology, zoom settings, legend, popup information, and a location search function.
Data source (name, URL, which layer type you used, and why you picked it): I added the LA_greenspace layer feature layer. https://services3.arcgis.com/kfmqp6kwSeDnDKNY/ArcGIS/rest/services/LA_greenspace/FeatureServer/0. I picked it because I'm interested in the environment, and it was a similar type of data as in the original sample.

### Component I added
The component I added was a location search function, in the top left of the map.
